# Expense Tracker

A basic expense tracker built with **React**, **Tailwind CSS**, and **Vite**. This application helps you track your expenses efficiently while leveraging local storage for data persistence.

## Features

- Add, edit, and delete expenses
- Real-time expense tracking
- Uses local storage to save your data
- Clean and responsive UI with Tailwind CSS

> **Note:** When you log out, your data will be deleted as the account is effectively removed.

## Tech Stack

- **Frontend:** React (with Vite for fast builds)
- **Styling:** Tailwind CSS
- **Data Storage:** Local Storage

## Getting Started

Follow these steps to set up and run the project locally:

### Prerequisites

Ensure you have the following installed:

- [Node.js](https://nodejs.org/) (v18 or later)
- npm or yarn

### Installation

1. Clone the repository:

    ```bash
    git clone https://github.com/your-username/expense-tracker.git
    cd expense-tracker
    ```

2. Install dependencies:

    ```bash
    npm install
    # or
    yarn install
    ```

3. Start the development server:

    ```bash
    npm run dev
    # or
    yarn dev
    ```

4. Open your browser and visit:

    ```
    http://localhost:5173
    ```
